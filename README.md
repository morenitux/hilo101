# Apoyo para Jefes de Reguladores

**Menos tiempo buscando. Más información a la mano.**

Un sitio para tener cerca los textos, tablas y documentos de consulta del Metro. Pensado para usarlo tanto frente a una computadora como desde el teléfono, con búsquedas rápidas y acceso directo a los archivos.

## ¿Qué puedes consultar?

- **Larines y traslados:** busca por clave o palabras y toca la descripción corta para copiar el texto completo.
- **Formación de trenes:** consulta por línea y busca motrices o carros, incluso varios números separados por comas. Toca una matrícula para copiar el tren y su modelo; esta función está pendiente en Línea 12.
- **Fracciones de vuelta:** tablas por línea, accesibles desde el menú.
- **Manuales y procedimientos:** busca documentos y abre sus PDF. Los manuales están agrupados en Transportes, Línea A, Línea B y Línea 12.
- **Otros recursos:** perfiles de línea, diagramas de servicios provisionales por estación y anuarios.

Los buscadores reconocen palabras sin acentos y variantes de singular y plural, y resaltan las coincidencias. Pulsa **`/`** para empezar a buscar y **`Esc`** para salir del cuadro.

## Pruébalo

Abre **`index.html`** en tu navegador o utiliza Live Server desde tu editor. No necesitas instalar dependencias ni compilar.

Conserva las carpetas junto a los archivos HTML:

```text
css/     Estilos
js/      Búsqueda e interacciones
img/     Imágenes del sitio
files/   Manuales, procedimientos, perfiles, diagramas y anuarios
```

Necesitas conexión a internet para cargar **Bootstrap 5** y la fuente **Arimo**. El resto está construido con HTML, CSS y JavaScript.

## Un proyecto que sigue creciendo

Los datos de las tablas se pueden editar directamente en los HTML. Para agregar o reemplazar documentos, guarda el archivo en su carpeta dentro de `files/` y actualiza el enlace correspondiente. Algunos nombres de procedimientos siguen pendientes de completar.
