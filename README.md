# Apoyo para Jefes de Reguladores

Sitio de consulta y apoyo para la operación del Metro. Incluye Larines y traslados, formación de trenes, fracciones de vuelta, manuales, procedimientos, otros recursos y disponibilidad de trenes.

## Uso

Abre `index.html` en un navegador o ejecuta el sitio con Live Server. No requiere instalación ni compilación. Se necesita conexión a internet para cargar Bootstrap y la fuente Arimo.

Pulsa `/` para enfocar la búsqueda y `?` para consultar los atajos de teclado.

## Archivos

- `*.html`: páginas y datos de consulta.
- `css/`: estilos.
- `js/`: búsqueda e interacciones.
- `files/`: documentos y recursos descargables.
- `img/`: imágenes e iconos.

La configuración operativa y las capturas se guardan en `localStorage` del navegador; no se sincronizan entre equipos.
